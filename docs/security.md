# 解压安全

文件名按不可信 UTF-8 路径处理。提取拒绝绝对路径、父目录跳转、盘符、反斜杠、符号链接、硬链接和特殊条目。允许 TAR 路径使用常见的 `./` 前缀。Core 从打开的目标目录描述符开始，通过 `openat`、`mkdirat` 和 `O_NOFOLLOW` 逐级访问目录。现有符号链接和非预期文件类型会被拒绝。提取只创建普通文件和目录，归档权限、所有者、ACL 和扩展属性不会应用到目标目录。

默认限制为每文件 4 GiB、实际解码合计 16 GiB、10,000 个条目、32 级路径、全归档 1000:1 展开比。已知尺寸在写入前检查，流输出在每个读取块后再次检查。已知 TAR 外层压缩只打开一层。Core 在归档读、块处理和提交时检查取消。固实压缩或顺序容器可能需要读取被跳过的条目，相关解码量计入预算。

普通文件先写到同目录的独占临时文件。数据完整读取后原子发布。冲突策略支持停止、跳过、替换普通文件及独占发布编号副本。替换时检查常规文件类型和输入文件身份。移除顶层目录时，Core 按原始深度预算先验证所有所选路径，再只移除精确匹配的一层。取消和常规错误会清理正在写入的临时文件，先前已发布的文件及已创建目录会保留。对于使用硬链接发布的文件系统，目标存储需要支持该操作。目标目录应由调用者控制，不与不受信任的本地进程并发重命名或修改。进程被强制终止时，同目录临时文件可能残留。

App 在安全输入框提交后清空输入，最近记录和任务历史不保存密码。打开文件名加密的 7z 或 RAR5 时，密码保留在内存中的归档清单，供预览和提取复用。

「保存此压缩包的密码」启用时，App 在成功解锁或提取后将密码和归档关联写入系统钥匙串，并关闭钥匙串同步。iOS 和 iPadOS 使用仅在本机解锁时可访问的钥匙串条目。密码库可以手动添加或删除密码，删除时同时移除相关的归档关联。磁盘上的归档以按顺序读取的分卷内容和格式配置生成指纹，改名后仍可匹配。嵌套归档的提取可使用密码库，关联目前用于可从文件系统重新打开的归档。

对于已关联的归档，App 自动尝试对应密码。逐一尝试整个密码库需由用户主动发起。SDK 在写入前按顺序对候选密码完整校验选中的加密文件内容。只有密码相关错误会尝试下一条。取消、超限和其他解码错误会终止。解压时临时文件只有完整读取并通过校验后才提交。

7z AES 的 CRC-32 能检出常见密码错误和数据损坏。Core 将 7z 密钥派生限制为单个密码派生最多 2²² 轮、每个驱动句柄累计最多 2²⁴ 轮，并限制加密文件名索引的解码输入和输出各为 16 MiB。派生会定期响应任务取消。该格式本身的 CRC-32 无法提供密码学完整性验证。

读取固实 7z 或 RAR5 条目时，解码器有时需要展开同一压缩块中更早的内容。展开并跳过的字节也计入总展开预算。

RAR5 对单个密钥限定 PBKDF2 迭代指数至 20，每个密码解码状态累计至多 2²⁷ 轮。派生定期响应取消。加密文件名按 RAR5 的 2 MiB 头部上限读取，文件按压缩块解密和校验。

文件内容预览在私有临时目录中暂存单个普通文件，使用生成的文件名和允许的类型后缀。除用户配置的解压限制外，单文件预览默认最多暂存 32 MiB，可在缓存管理中调低。读完条目并通过驱动校验后才显示内容。关闭预览、取消或读失败会清理暂存文件。正在使用的目录持有文件锁，清理程序只处理可独占访问的预览目录。进程异常退出后，默认在下次进入前台清理闲置预览。旧版本创建的目录在超过 24 小时后纳入清理。

输出预算约束读取到调用方的解码量。解析容器索引和编解码器内部工作集仍由固定版本的 libarchive 和解码依赖控制。进度以条目为单位，已知大小的文件显示块级进度。

取消文件访问时，Apple SDK 会同时取消系统文件协调和 Core 操作。磁盘空间不足、系统后台时间耗尽或用户取消而正常返回时，Core 会清理当前暂存文件并保留已发布的文件。系统直接终止进程时，App 会在下次启动报告上次任务中断。

GZIP 解码器读取到每个成员的尾部时会校验 CRC-32 和 ISIZE。独立 `.gz` 提取会读完整个流，验证失败时清理暂存文件。提前结束的读取、选定 TAR 条目提取以及已经发布的文件仍遵循逐文件提交规则。

嵌套挂载由调用方显式发起。Core 使用现有解码上限，并检查祖先链的嵌套层数及暂存字节数。嵌套归档完整读取后才进入下一层识别。调用方提供自己控制的暂存目录，文件在写入之前解除目录链接，随最后一个读取句柄关闭而释放。
