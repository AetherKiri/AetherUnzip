# AetherUnzip 项目规格

## 产品目标

AetherUnzip 是一个 MIT 许可的归档与资源处理 Monorepo。首个产品是 macOS、iOS 和 iPadOS 原生 SwiftUI App。相同的 Core 可通过 C ABI 独立集成，服务于归档识别、流式读取、资源枚举和安全提取。

## 当前版本 0.1.x

| 层 | 交付与约定 |
| --- | --- |
| Core | C17/C++17 工具链、CMake 3.24+、POSIX 文件 I/O。提供 C ABI、静态驱动注册、文件/内存/切片/拼接/回调源、文件/内存/回调 sink、归档游标、资源路径索引、组合挂载、受限嵌套挂载和提取。 |
| 驱动 | 通用归档使用 libarchive，独立 `.br` 压缩流使用 Brotli 驱动，KiriKiri 资源容器使用 XP3 驱动。识别以文件签名和结构为准，扩展名用于辅助确认。 |
| Swift SDK | Swift 6、Swift Package Manager、本地 XCFramework。提供归档清单、格式配置、异步条目枚举、单文件按需流式读取、提取进度、取消及错误映射。 |
| App | macOS 14+、iOS/iPadOS 17+。提供系统文件导入、ZIP/7z/RAR 分卷导入、目录树、文件内容预览、嵌套归档浏览、全部或选定文件提取、ZIP 密码输入、目标选择、任务历史和提取设置。 |
| 构建 | Core 可独立构建并运行 C CLI。Apple 构建脚本生成通用 macOS、iOS arm64 真机和通用模拟器的库。GitHub Actions 配置 Linux Core 及 Apple 构建和测试。 |

Core 按 POSIX 平台设计，本地验证覆盖 macOS 与 Ubuntu 24.04 ARM64。Apple 验证覆盖 macOS 实际文件面板流程、iPhone/iPad 模拟器启动和 iOS 真机目标的未签名构建。

### 格式和能力

- 样本范围包括 ZIP/ZIP64、ZipCrypto、WinZip AES-256、7z LZMA2、单卷与独立卷 RAR/RAR5、USTAR、CAB、ISO 9660 和 LZH。ZIP/ZIP64 还验证了磁盘编号分卷。GZIP、LZ4、Zstandard、XZ、BZIP2 分别覆盖独立流及 TAR 组合，Brotli 覆盖单个独立流。独立流展示一个合成文件条目。
- 文件和内存源支持偏移读取，回调源可声明顺序读取、偏移读取和固定长度。当前归档驱动需要可随机访问且长度已知的源。归档条目和挂载文件按顺序读取。
- App 使用 Quick Look 预览常见文本、图片和 PDF，复用 Core 读取与预算检查。预览另有每文件 32 MiB 上限。
- XP3 支持标准 KiriKiri 容器，包括链式索引、UTF-16LE 路径与混合分段。Core 和 App 使用相同的读取与安全提取流程。
- 用户可为具有固定签名和偏移的包装文件显式选择格式配置。Core 识别并验证切片的内层格式。[格式配置](format-profiles.md)
- 具体编码方法、识别边界和验证样本以[驱动文档](drivers.md)为准。

### 安全和生命周期

- Core 将写入约束在调用方指定的目录内，拒绝路径穿越、链接和特殊条目，并在写入路径执行单文件大小、总解码量、条目数、路径深度和展开比限制。
- 普通文件逐个暂存并发布。取消或失败清理当前临时文件，保留已发布文件。冲突策略为停止、跳过或替换普通文件。
- Swift SDK 在后台协调读写并持有相应的 Security-Scoped URL 访问权限。选择性提取使用预览时的条目索引和元数据，输入变化时要求重新打开。
- C ABI 当前处于预览期。对象所有权、UTF-8、结构版本和并发约定见 [API 文档](api.md)。逐文件提交和 GZIP 校验边界见[安全文档](security.md)。

## 验收标准

| 验收项 | 通过条件 |
| --- | --- |
| Core 闭环 | C CLI 可列出 ZIP 条目、按路径读取文件，并将归档提取到现有目录。CTest 验证 I/O、格式识别与样本输出、资源索引、目录游标，以及嵌套挂载的预算与清理。 |
| 安全策略 | CTest 验证路径穿越、链接、资源上限、冲突策略和取消。中断后当前文件的临时输出被清理。 |
| Swift SDK | Swift 测试覆盖调用 Core、枚举、按需读取及字节上限、选定提取、进度、取消、错误映射、输入变更、ZIP 密码校验、GZIP 损坏处理及 ZIP/7z/RAR 分卷排序、缺卷提示和提取内容。 |
| Apple App | macOS、iOS 模拟器和 iOS 真机目标通过构建。使用原生文件面板导入 ZIP，查看条目与文件预览，进入内层归档，选择目标目录，并核对实际解压文件。 |
| 格式或能力扩展 | 有对应构建配置和来源明确的测试样本。测试覆盖识别、条目枚举与提取内容。文档同步更新实际支持边界。 |
